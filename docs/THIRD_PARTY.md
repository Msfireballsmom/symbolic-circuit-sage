# Third-party software

Circuit Sage does not vendor circuit engines, schematic editors, or OCR libraries. The drawing canvas, Fourier checks, and exam keys in this repository are project code.

Every package below is declared in `package.json`. The license is the `license` field of the installed package. All of them allow commercial use. None are GPL or AGPL.

The schematic editor does not depend on an external drawing library.
